# Agora — refonte

Agora fait travailler des agents dans des sandboxes, garde leurs échanges et retrouve le
travail après une interruption. Cette branche repart de zéro : aucune décision des versions
précédentes n'est reprise sans être écrite ici.

| Dossier | Contenu |
| --- | --- |
| [docs/](docs/) | La conception : produit, back-end des sandboxes, interface. |

Le code du back-end des sandboxes se développe sur la branche `feat/sandbox-backend`,
partie de celle-ci.

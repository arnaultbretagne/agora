# Parked ADRs

These documents preserve earlier decisions while the ADR sequence is being remodelled.

They are retained for comparison only. They are not part of the active ADR chain and do not govern
the current design.

Some implementation comments, plans and specifications still cite these historical numbers while
the remodel is under review. Those citations refer to the parked file with the matching original
title; they must not be reinterpreted against a reused number in the active series. The callers will
be aligned explicitly after the replacement decisions are accepted.
